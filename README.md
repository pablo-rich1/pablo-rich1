## Trabalho atual

### Report AI

Atualmente desenvolvo o **Report AI**, um SaaS privado e AI-first voltado para engenharia documental e fluxos de produção.

Meu trabalho envolve:

- Prompt Engineering e Engenharia de Contexto
- Orquestração multi-provider de LLMs
- Retrieval / RAG
- Structured Outputs e validação de saída
- Gestão de tokens, contexto e custos
- Desenvolvimento de software assistido por IA
- Testes automatizados e QA
- Desenvolvimento full-stack com TypeScript, React, Supabase e PostgreSQL

O repositório principal do produto é privado. Os projetos públicos deste perfil são usados para demonstrar conceitos de engenharia sem expor código proprietário, prompts internos, arquitetura sensível ou dados privados.
